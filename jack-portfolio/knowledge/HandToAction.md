# Component: HandToAction

## Overview
The `HandToAction` component is the footer call-to-action area of the portfolio. It serves as the primary conversion point for professional networking.

## Implementation details
- **Visuals**: Uses native React mapping of arrays to create a dot-matrix hands visual.
- **Interactivity**: Houses a transparent overlay hot-spot for the LinkedIn profile link.
- **Token Usage**: Obsidian background background, Graphite borders, Signal White pill buttons.
- **Responsive**: Scales via CSS layout transitions rather than pixel-fixed transforms.

## Dependencies
- `framer-motion`: Used for dot opacity transitions.
