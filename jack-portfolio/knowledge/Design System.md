# Design System

## Color Palette
The aesthetic is built on the Obsidian background with high-contrast UI elements.

| Name | Role | Value |
| :--- | :--- | :--- |
| **Obsidian** | Page Canvas | `#101010` |
| **Chalk** | Text/Icons | `#f3f3f3` |
| **Graphite** | Borders | `#212121` |
| **Compass Gold**| Icons | `#6f6759` |
| **Signal White**| Actions | `#ffffff` |

## Typography
- **Primary:** Acumin Pro/Inter (Weight 400). Never bold.
- **Display:** 63px/1.05 height, -0.69px tracking.

## Components
- **Pill Buttons:** `9999px` border-radius, pure white fill.
- **Card Premium:** `8px` radius, 1px Graphite border.
