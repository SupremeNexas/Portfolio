# Portfolio

A modern, animated portfolio landing page built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- **Hero Section**: Full-screen hero with magnetic hover effect on portrait
- **Marquee Section**: Horizontal scrolling image marquee driven by page scroll
- **About Section**: Character-by-character scroll-reveal text animation
- **Services Section**: Five services with staggered fade-in animations
- **Projects Section**: Sticky card-stacking effect with 3 project showcases

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
